# 0019 — One command to install: a Home folder, the page inside the wheel, setup in the terminal

Status: accepted · 2026-10-12 · built (plan `docs/plans/2026-10-12-002`, M1).

**Decision.** A stranger on Windows needs only `uv` (and Chrome or Edge). `uv tool install <the Release's wheel>` fetches Python 3.12 and makes its own environment; `stepout` starts the chat and opens the browser. Three choices make that true:

1. **Home.** Every data path (chats, Memory, logs, screenshots, the key, grants.toml) derives from one function, `paths.home()`: `STEPOUT_HOME` if set, else `data/` when run from a source checkout (development is unchanged), else `%LOCALAPPDATA%\Stepout`. Never the working directory, never the package, so an upgrade keeps everything. Home is on the Files block list next to the source tree: the agents cannot read the key or the chats.
2. **The page ships inside the wheel.** Vite builds into `src/stepout/_web/` (git-ignored), package data puts it in the wheel, and CI (`.github/workflows/release.yml`) builds it on every tag and proves the wheel installs on a clean Windows runner (`scripts/smoke_install.py`) before attaching it to the Release. Nothing built is committed; a source checkout still needs Node once.
3. **Setup is a terminal act by the User.** `stepout init` asks for the key (hidden, checked with a free `models.list` call, a refused key writes nothing) and then runs `stepout grant`, which offers Documents, Downloads and Desktop or another folder and asks per folder for names-only or read. A whole drive or the profile folder is offered as a tick list of its top-level folders; allowing all of it takes typing its name. `init.write_grants` is the only writer of grants.toml, so "only the User edits it" stays true: the page, the model and a phone cannot widen the Grants. `stepout` offers `init` once when the key or the folders question is missing and someone is at the keyboard (both stdin and stdout a terminal: on Windows the null device counts as one).

**Also.** `mem0ai` became the optional extra `stepout[mem0]` (it was only imported with `OPENAI_API_KEY` set, and it is most of the install); without it Memory says so and uses plain files. The browser tries Chrome, then Edge, which every Windows machine has. Off Windows the file hands fail closed: the block list is Windows paths.

**Limits.** The install line names a version (a wheel URL must carry one); PyPI (`uvx stepout`) would shorten it but is a public name claim, so not yet. An existing `./data` is not found by an installed copy unless `STEPOUT_HOME` points at it (no silent move). `STEPOUT_HOME` is read from the real environment, not from a `.env`. Only the Anthropic key is asked for; another provider's key is still a line in Home's `.env`.
