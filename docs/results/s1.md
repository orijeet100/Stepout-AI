# S1 result — domain core

Date: 2026-10-07

## What's built
Domain types (`domain.py`), Gate `screen`/`check` (`gate.py`), Intake with the cheap-model (Haiku 4.5) fallback (`intake.py`), Runner's fetch/search loop on Sonnet 5 (`runner.py`), Fetcher with network policy (`fetch.py`), Store + Ledger on SQLite (`store.py`, `ledger.py`), Model port + Anthropic adapter (`model.py`), CLI Channel (`channels/cli.py`), composition root (`app.py`).

## Live demo — done (2026-10-07)
Run by hand against the real API, from the terminal (`python -m stepout.app`) and from the web chat (`python -m stepout.app web`):
1. `pay this invoice` → Declined, reason + alternative, $0.
2. `what does 2 + 3 equal?` → answered, $0.019.
3. `top news in New York City today` → Lookup, seven current stories from web search, $0.26 (over half the $0.50 Task cap).

**Bug found live, fixed:** a request with no tools sent `tools=null`, which the API rejects (`tools: Input should be a valid array`). That broke the cheap-model routing call, which only runs for short requests (3 words or fewer, no `?`), e.g. `what is 1+2`. The offline suite never hit it. Fixed in `model.py` with a regression test (`test_model.py`).

**Still open:** the news answer has no source links (FR4 wants citations — the model's citations are dropped because only text blocks are kept); the $0.50 cap is checked only before a call, so one expensive search can overshoot it; the Windows console shows `�` for non-ASCII dashes in the CLI.

## Deviations from the plan
- `test_runner.py` and `test_app.py` use fake Fetcher/Channel doubles rather than driving the real `Fetcher` over a loopback HTTP server — `Fetcher`'s own network policy correctly blocks `localhost`/`127.0.0.1`, so a real loopback server can't be used to test it without weakening the policy. `Fetcher`'s own happy path and blocklist are tested directly in `test_fetch.py` instead, using a monkeypatched DNS lookup and `httpx.MockTransport` — still offline, still real code, no policy weakening.
- Pricing is a hardcoded `$/Mtok` table (`model.PRICING`) per ADR 0001, confirmed against current list prices (Haiku 4.5 $1/$5, Sonnet 5 $3/$15, web search $10/1000 uses) rather than guessed.
